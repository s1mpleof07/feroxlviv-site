# FEROX LVIV — Official Website

Сайт компанії FEROX LVIV — металообробка та дизайн з кортену у Львові.

## Структура

- `build.js` — генератор статичного сайту (Node.js)
- `src/` — джерела (CSS, JS, шаблони)
- `build/` — згенерований сайт (автоматично створюється)
- `netlify.toml` — налаштування деплою

## Як редагувати

### Через GitHub (без термінала)
1. Відкрий потрібний файл на github.com
2. Натисни на олівець (Edit)
3. Зроби зміни
4. Внизу — Commit changes
5. Netlify автоматично перебудує сайт за 1-2 хвилини

### Локально
```bash
npm install
node build.js
# Відкрий build/index.html в браузері
```

## Що де редагувати

| Що змінити | Файл |
|------------|------|
| Тексти послуг, ціни, типи виробів | `build.js` (масив `services`) |
| УТП блок "Чому ми" | `build.js` (масив `whyUs`) |
| Матеріали (модалка) | `build.js` (масив `materials`) |
| SEO-тексти на сторінках послуг | `build.js` (об'єкт `seoTexts`) |
| Проекти портфоліо | `build.js` (масив `projects`) |
| Дизайн (кольори, шрифти) | `src/styles.css` |
| JS-логіка | `src/script.js` |

## Деплой

Сайт автоматично деплоїться на Netlify при кожному push в `main`.

URL: https://feroxlviv.netlify.app
